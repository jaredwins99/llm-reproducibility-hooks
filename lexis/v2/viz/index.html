Lexis

Does the linguistic repertoire a question lives in change the answer a model gives?

Why is there more than one lexis?

A lexis, as this project uses the word, is a bounded repertoire: the set of things a speaker can say, defined mostly by what they cannot — vocabulary that isn't available, abstraction that has no words, hedges that don't exist, syntax that never gets used. This is Basil Bernstein's distinction between restricted and elaborated codes: not slang layered on top of a shared language, but genuinely different envelopes of expressible meaning.

Multiple lexes aren't an artifact of this experiment — they are the natural state of language, because every speech community's repertoire is shaped by different pressures:

Each of these registers is produced by its community's constraints, not by anyone's opinion on any topic. That independence is the experimental lever: if the same question, pinned to the same truth conditions, gets a different answer when asked from inside different repertoires, then the repertoire itself — not the content — moved the answer.

One demand, six repertoires

The veganism demand ("would a fully vegan diet be, on balance, better…"), rendered by the translator into each lexis in pilot 2. The respondent is never told the register's rules — the rendering's off-topic examples are its only teacher. Expand to read:

How a trial works

A — demanda topic's question with pinned truth conditions (modal, decision rule, scope, comparison)
→
B — rolea speech community; never sees the topic
→
C — lexisthe role's bounded repertoire; never sees the topic
→
D — translaterenders the demand into the lexis; a haiku drift gate checks it against the truth conditions, up to 2 retries
→
E — respondfresh model answers YES/NO; one call per arm

Three paired arms per trial: lexis (the gated rendering), neutral (the same demand thoroughly reworded into a bland institutional register, also gated), and control (the bare demand). A flip = that arm's answer differs from control in the same trial.

Read the answers

Every response the respondent gave, verbatim — topic → role → the three arms. In the lexis arm the model answers in the register it was addressed in, having never been told the register's rules.

Is the control even stable?

The control prompt is byte-identical within a topic — six runs, six roles. Any variation here is pure sampling noise in the respondent.

What pilot 2 actually found

1 — The register effect did not survive the drift gate. With semantics pinned, plain rewording flips answers almost as often as the lexis does (McNemar ). Pilot 1's apparent lexis effect was carried largely by semantic drift — the translator adding considerations, intensifiers, and modal shifts — which the gate now removes (it forced retries on lexis renderings, and zero neutral ones).

2 — Our own precisification was a treatment. Rewriting "should the average adult go vegan" as "would it be, on balance, a better choice" flipped the model's baseline from NO to YES. A chunk of what reads as a model's "stance" lives in the question's ambiguity, and there is no neutral way to remove that ambiguity.

3 — Pinned demands sit nearer the decision boundary. The lab-meat control went N N N Y N Y across byte-identical prompts. Near the boundary, single-draw flips conflate noise with effect — the next step is replaying the frozen per-trial bundles ~5× per arm and testing arm effects on flip probabilities instead of single flips.
